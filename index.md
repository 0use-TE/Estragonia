# Estragonia

Avalonia UI inside Godot 4 (Vulkan / Skia).

> **AI-assisted codebase.** Stability is **not** guaranteed. Maintainers review changes; you still need to test.

Based on the original [Estragonia](https://github.com/MrJul/Estragonia) by **Julien Lebosquain** (MIT).

## Packages & source

- NuGet library: [Ouse.Estragonia](https://www.nuget.org/packages/Ouse.Estragonia/)
- NuGet template: [Ouse.Estragonia.Templates](https://www.nuget.org/packages/Ouse.Estragonia.Templates/)
- GitHub: [0use-TE/Estragonia](https://github.com/0use-TE/Estragonia)

```bash
dotnet new install Ouse.Estragonia.Templates
dotnet new estragonia -n MySolution --GodotProjectName MyGame -o MySolution
```

Then open `project.godot` with Godot 4.7+ (.NET).
